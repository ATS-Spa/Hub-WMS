Accesso e Login

Il modulo Presenze richiede l'autenticazione con un account Google. L'accesso viene gestito tramite un file di configurazione nella cartella Drive condivisa.

1
Schermata di login
Alla prima apertura (o dopo il logout) compare la schermata di accesso. Clicca il pulsante Accedi con Google.
WMS · Presenze
📋 Cooperativa & ATS · Gestione Mensile

Accedi con Google per visualizzare e gestire i fogli presenze. L'accesso ai dati è regolato dal profilo assegnato.

L'accesso è regolato da config_presenze.json nella cartella Drive condivisa.

2
Profili di accesso
Ogni utente ha un profilo definito dall'amministratore. Il profilo determina cosa puoi vedere e fare.
VIEWER
Visualizzatore
Può solo visualizzare i fogli presenze delle sezioni a cui ha accesso. Non può modificare i dati.
ADMIN
Amministratore
Può visualizzare e modificare le presenze. Ha accesso alla modalità Admin (celle editabili). Può gestire il tab File Import.
SUPER
Super Utente
Accesso completo a tutte le funzioni inclusa la gestione dei permessi utente (tab Permessi).
⚠️
Se compare "Accesso Negato", il tuo account Google non è ancora autorizzato. Contatta l'amministratore del sistema per richiedere l'accesso.
3
Barra in alto dopo l'accesso
Una volta entrati, la topbar mostra il tuo nome, il ruolo e i pulsanti Admin ed Esci.

Interfaccia · Passo 3 di 8

Sezioni del Modulo

Il modulo Presenze è diviso in tab (sezioni) accessibili dalla barra di navigazione interna. Ogni tab ha uno scopo preciso.

●
Cooperativa — Tab principale
Mostra il foglio presenze dei dipendenti della cooperativa. Colonne per ogni giorno del mese, righe per ogni dipendente. Solo la sigla X (presenza) è disponibile per questa sezione.
●
ATS — Dipendenti diretti
Foglio presenze dei dipendenti ATS. Supporta tutte le sigle (ferie, malattia, permessi, ecc.) e la visualizzazione delle ore ordinarie/straordinarie.
●
File Import — Solo Admin
Permette di importare dipendenti da un file Excel o da Google Sheets. Disponibile solo per utenti con ruolo Admin o Super.
●
Permessi — Solo Super
Gestione degli accessi utente. Aggiunta, modifica e rimozione di utenti autorizzati. Visibile solo al Super Utente.

Clicca ✔ Presenza a Tutti

Configura l'operazione di massa

Distribuzione ore su commessa (opzionale)

1
Aggiungere un dipendente manualmente
Con la modalità Admin attiva, clicca ＋ Dipendente nella barra filtri. Inserisci nominativo, matricola/SAP, responsabile e plant.

2
File Import (tab dedicato)
Il tab File Import permette di importare in blocco i dipendenti da un file Excel o da un Google Sheet. Disponibile per gli Admin.
  • Seleziona il file Excel (.xlsx) contenente l'anagrafica dipendenti
  • Il sistema legge nome, matricola, responsabile e plant dal foglio
  • Visualizza un'anteprima delle righe importate prima di confermare
  • I dipendenti vengono aggiunti al mese correntemente selezionato
3
🗂️ Genera File Anno Completo
Disponibile nel tab File Import, questa funzione crea in automatico tutti i file mensili di un anno per uno o più responsabili, leggendo la lista dipendenti da un file template di riferimento.
  • Seleziona il file template di riferimento (il mese da cui leggere i dipendenti) e l'anno da generare
  • I dipendenti ATS vengono letti dal foglio Mese_ATS del template e scritti nel foglio _ATS di ogni nuovo file
  • I dipendenti Cooperativa vengono letti dal foglio Mese_Coop del template e scritti nel foglio _Coop di ogni nuovo file
  • Ogni file contiene le righe Sigla / Ingresso / Uscita / Pausa per ogni dipendente, pronte per la compilazione
  • I file vengono creati direttamente su Google Drive nella cartella configurata
💡
Se il foglio _Coop del template è vuoto o assente, la generazione continua comunque: il foglio Coop nei nuovi file verrà creato senza dipendenti e potrà essere compilato manualmente.
4
📅 Inserimento Massivo per dipendente
L'inserimento massivo applica una sigla a un singolo dipendente su un range di date multi-mese. Disponibile per Admin.
  • Seleziona il dipendente, la sigla, il range Dal/Al (anche su mesi diversi) e gli orari
  • I giorni festivi e i weekend vengono saltati automaticamente
  • Se la sigla è F (Ferie), il residuo ferie viene aggiornato automaticamente
  • Puoi aggiungere una nota che verrà scritta nelle celle corrispondenti
  • I file Drive interessati vengono aggiornati mese per mese in sequenza
5
🌴 Richieste Ferie — flusso completo
Il modulo Richieste Ferie gestisce l'intero ciclo: il dipendente invia la richiesta, il responsabile approva o rifiuta, e il sistema notifica via email e aggiorna automaticamente il foglio presenze.
  • Dipendente: apre il pannello Richieste, indica il range di date, la tipologia e una nota opzionale, poi invia
  • Responsabile: riceve una notifica email e vede la richiesta in stato In attesa
  • Clicca ✅ Approva o ❌ Rifiuta: si apre un popup di conferma
  • In caso di approvazione: il campo Nota è opzionale — puoi lasciarlo vuoto o aggiungere un messaggio che arriverà nella mail al dipendente
  • In caso di rifiuto: il campo Nota è obbligatorio — devi inserire una motivazione prima di poter confermare
  • Il dipendente riceve la mail di esito con stato e motivazione; il foglio presenze viene aggiornato automaticamente per le approvazioni
❌ Rifiuta richiesta
Rifiutare la richiesta di Mario Rossi (01/06 → 05/06)?
Nota (obbligatoria)
💡
La nota del responsabile (approvazione o rifiuto) arriva nella mail di esito al dipendente come campo Motivazione. Per l'approvazione è facoltativa, per il rifiuto è sempre richiesta.

Tabelle e Schede

I dati sono organizzati in tre tab corrispondenti ai tre fogli del file Excel: Intestazione, Dettagli Carico e Dettagli ODP.

●
Intestazione — Dati principali spedizione
Una riga per ogni documento di spedizione (DocNum). Contiene data, tipo, plant, commessa, destino, AWB, numero colli e peso totale.
●
Dettagli Carico — Pallet caricati
Una riga per ogni tipo di pallet caricato nella spedizione. Contiene quantità, volumi, pesi e altri attributi logistici. La colonna DESTINO è mostrata come prima colonna extra per facilitare la lettura.
●
Dettagli ODP — Ordini di prelievo
Una riga per ogni ODP (Ordine Di Prelievo) collegato alla spedizione. Contiene numero ODP, quantità e attributi specifici del prelievo.

Operatività · Passo 6 di 9

Inserire AWB

L'AWB (Air Waybill) è il codice di tracking della spedizione. Puoi applicarlo a una o più righe filtrate in un'unica operazione direttamente dal pannello arancione in cima.

1
Pannello inserimento AWB
In cima alla pagina (sotto la topbar) c'è sempre visibile il pannello AWB con sfondo scuro. Digita il codice AWB nel campo e premi Applica AWB oppure Invio.
Inserisci AWB
2
Filtro destino prima dell'AWB
Il sistema applica l'AWB a tutte le righe attualmente filtrate. Se ci sono più destini nei risultati, l'operazione viene bloccata. Filtra sempre per un singolo destino prima di applicare.
⚠️
Regola fondamentale: Un codice AWB non può essere usato per destini diversi. Il sistema blocca l'operazione se rileva un conflitto e mostra un avviso dettagliato con i documenti coinvolti.
💡

Copia ODP

La funzione ODP Smart Copy raccoglie tutti i numeri ODP delle righe filtrate, li comprime e li divide in scaglioni pronti per essere incollati in SAP o altri sistemi con limite di caratteri.

1
Apri il pannello ODP
Clicca il pulsante ODP nella barra filtri (attivo solo se i dati sono caricati). Si apre la finestra con gli ODP raggruppati per destino, tipo e data.
2
Modalità Compatto vs Solo+
Scegli la modalità di compressione:
Compatto raggruppa gli ODP con prefisso comune usando il carattere + (es. ORD001+234+235).
Solo+ lista tutti gli ODP uno per uno separati da ;.
3
Scaglioni e copia
Gli ODP sono divisi automaticamente in scaglioni da max 30 caratteri. Ogni scaglione ha il suo pulsante Copia. Usa 📋 Copia tutto per copiare tutti gli scaglioni in una volta.

FLM e VLT

VLT è il nome del sistema del cliente usato dalla commessa FLM. Sia il pulsante VLT che il pulsante FLM sono presenti esclusivamente per la commessa FLM: serve comunicare con il sistema VLT del cliente per la chiusura degli item entrati. Le altre commesse registrano le GR normalmente, senza nessuna integrazione esterna.

1
VLT — Sistema del cliente FLM
VLT è il sistema esterno del cliente FLM. Il GRN Manager si connette ad esso per scaricare i dati necessari alla validazione delle righe DDT (item attesi, quantità, riferimenti). Il caricamento avviene automaticamente all'accesso quando si è sulla commessa FLM.
ℹ️
Il pulsante ↻ VLT nella topbar aggiorna i dati dal sistema VLT senza ricaricare la pagina. Utile se nel frattempo il cliente ha aggiornato i dati sul suo sistema.
2
FLM — Chiusura item per la commessa FLM
Il pulsante 📡 FLM è attivo solo per la commessa FLM. Invia i dati delle bolle aperte allo script Tampermonkey installato nel browser, che comunica con il sistema del cliente per chiudere gli item entrati. Le altre commesse non usano questo flusso: le loro GR vengono salvate normalmente senza nessun invio esterno.
📡 FLM attivo — 3 bolle aperte in coda per SAP B1
⚠️
Il pulsante FLM funziona solo se lo script Tampermonkey è installato e attivo nel browser. Se non appare nulla dopo il clic, verifica che l'estensione sia abilitata sulla pagina SAP B1.
3
Configurazione utente
Il modulo salva una configurazione per utente (plant preferito, filtri ricorrenti) su un file JSON in Google Drive. La configurazione viene caricata automaticamente ad ogni accesso.
